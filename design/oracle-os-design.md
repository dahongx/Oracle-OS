# Oracle OS — UI 设计规范 (Design Spec)

> 掌心仪式挂件的仪式型 UI 系统。滚轮驱动，非触摸。
> 本文件为设计基线，随产品/目标客户迭代。参考效果图见 `references/`。

## 1. 产品定位

一个通过**实体滚轮**完成「提问 · 旋转 · 沉静 · 揭示」的掌心仪式设备。
不是手机 App、不是掌机、不是电子宠物、不是游戏机——它应让用户感觉在**操作一台小型精密仪式仪器**（高端 EDC 仪式装置 + 机械表盘 + 护身符 + 精密仪器的结合）。

核心不是固定三个小游戏，而是一套完整的**滚轮驱动式微仪式交互系统**，玩法开放可扩展。

## 2. 硬件约束（决定 UI 的先决条件）

- 屏幕：正方形小屏，保持完整矩形（不做异形屏）。SPI 非触摸，只写不收。
- 输入：**唯一输入 = 右侧半嵌入式实体滚轮**（机身中间层，正面只见部分轮廓）。
  - 旋转 Scroll
  - 短按 Press
  - 长按 Long Press
- 触觉：LRA 线性马达（DRV2605L 驱动），旋转/按压/长按都应有触觉反馈。
- 低功耗小屏：动效要克制、缓慢、低帧率，避免复杂 3D、大量粒子、高帧率爆闪、多彩 RGB。

## 3. 交互原则（滚轮语义）

| 动作 | 语义 |
|------|------|
| **旋转** | 选择、调节、拨动、加速、生成能量、切换焦点。**速度越快能量越强**（速度反馈是核心表达）。 |
| **短按** | 确认、进入、捕捉、收藏、锁定结果。反馈：轻微锁定 + 亮点闪烁 + 短触觉。 |
| **长按** | 返回、取消、重置、进入系统菜单。反馈：环形进度填充 + 边缘渐亮。 |

界面必须**明确体现这种异形输入**：侧边滚轮提示、滚动焦点、旋转速度反馈、按压反馈、长按进度环、停转结果、侧边能量条 / 边缘光标。

## 4. 视觉规范

- **底色**：纯黑（低亮度 OLED 感）
- **主线条**：暖金 / 香槟金细线
- **元素**：极简星图、轨道、光点、几何符号，**留白充足**
- **气质**：高级、克制、神秘、精密、可量产。不过度游戏化。

### 色彩（来自效果图，待随产品调整）
| 用途 | 色值 |
|------|------|
| 高亮/主色 | `#F7F6F1` |
| 次亮 | `#EDE8D8` |
| 中间调 | `#D3CCB8` |
| 暖金线 | `#AEB3A1` |
| 暗部/背景线 | `#7D8276` |

> 注：效果图是偏"米白暖调"的示意版；产品实际是**黑底**，上表色值需按黑底重新定义为
> 「金色系线条在黑底上」的对比配色。这是效果图与最终定位的主要差异，实现时以黑底为准。

### 字体
- 像素字体（12x12 / 6x8），中英数字都要支持。
- 信息层级：核心内容（大号像素字/居中）> 辅助信息（小号像素字/次要色）> 状态指示（图标/进度/能量）> 装饰元素（低对比/不抢焦点）。

## 5. 界面流程 (Flow)

```
Boot(初始页) → Home(首页) → Mode Select(模式选择)
   → [各功能模式] → Reveal(结果页)
   → History/Vault(历史/收藏)   Settings(设置)
```

## 6. 功能模式（候选，开放可扩展）

不局限于以下，可提新模式（每日指引、呼吸校准、幸运信号、情绪罗盘、符号收藏、结果历史、今日护符…）。所有模式服务于同一定位。

1. **即时一问 / Quick Ask** — 提问(长按清空思绪) → 旋转聚拢星光 → 短按锁定揭示答案。结果：一句话建议 + 象征符号。
2. **轨道捕捉 / Orbit Capture** — 旋转调整轨道速度 → 在轨道上短按捕捉闪光符号 → 显示捕捉到的星象与讯息。结果：星象图案 + 简短讯息。
3. **三符占卜 / Triad Divination** — 旋转生成能量 → 每次短按抽一枚符号，共三枚 → 自动解读三符组合。结果：组合解读 + 指引。
4. **情绪罗盘 / Mood Compass** — 旋转定位当前情绪 → 短按确认生成情绪图谱 → 获得平衡建议。结果：情绪状态 + 调节建议。
5. **每日指引 / Daily Guide** — 查看今日主题 → 旋转查看细节方向 → 短按收藏关键指引。结果：今日主题 + 提醒。

## 7. 关键页面

Home / Mode Select / Ask Input / Orbit Tuning / Reveal / History / Settings

## 8. 结果页样式 (Reveal Styles)

文字指引 / 符号图案 / 星象图 / 情绪图谱 / 结合解读

## 9. 状态指示 (Status Indicators)

- **能量条**：旋转积累能量
- **焦点点**：当前选择焦点
- **进度环**：长按进度可视化
- **收藏标记**：已收藏此结果

## 10. 动效方向

- 旋转时：星轨、光点、符号、线条、波纹随速度变化（速度越快越密集）
- 停转时：动画收束成符号或短句
- 短按：轻微锁定反馈 + 亮点闪烁
- 长按：环形进度填充，边缘柔和渐亮
- 全程克制、缓慢、低功耗，适合小 OLED/LCD。
