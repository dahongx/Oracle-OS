## ✅ 已验证:USB 下载 + 串口打印(esp32s3_serial_test)

**结论:硬件没问题。** 通过 COM4(板子自己的 Type-C 原生 USB)烧录并观察到持续正常的心跳打印:
```
[   51399 ms] heartbeat #51 - ESP32-S3 running OK
[   52399 ms] heartbeat #52 - ESP32-S3 running OK
```
主控芯片、晶振、电源、Flash、原生 USB 全部确认工作正常。

### 调试串口打印时踩过的坑(以后可以跳过,直接看结论)

1. **调试/查看串口打印,必须用真正的终端软件(串口调试助手、Arduino IDE 串口监视器等),
   不要用脚本去手动摆弄 DTR/RTS。** ESP32-S3 原生 USB-CDC 的"host 已连接"状态判断依赖
   USB 层面的握手时序,脚本很容易触发不到这个状态,导致看起来"什么都没有打印",
   其实固件一直在正常跑,只是打印数据没能被正确读出来。
2. **用 esptool/脚本对着原生 USB 端口(COM4 这种 VID:PID=303A:xxxx 的原生设备)做复位,
   会被芯片 ROM 强制带进下载模式**(这是 ESP32-S3 的既定设计行为,不是 bug)。
   所以只要是脚本触发的复位,再去读串口永远只会看到 "waiting for download",
   必须要么用真正的终端软件保持连接,要么物理拔插 Type-C 让它真正上电复位。
3. **外接 CH340 转串口小板(接 J3 排针)这条路仅供参考,不是必须的**——这次实测中这块
   CH340 小板本身就是坏的/配置有问题(连自环测试都收不到),排查了半天接线、J2、固件才发现。
   **正常测试直接用板子自己的 Type-C 口(原生 USB)就够了,不需要额外接 CH340。**
   如果确实需要用 CH340 这条路径(比如需要看 App 启动最早期、原生 USB 还没初始化时的日志),
   记得先做一次 CH340 自环测试(TXD接RXD)确认这个转串口模块本身没问题,再往板子上接。

## 电源电路说明(重要,关系到以后写正式固件)

这块板子是标准的"一键开关机"电池供电电路(Q1/Q3 CJ3415 + Q2 SS8050 自锁):
- 按下 BUTTON,通过二极管拉低锁存节点 -> 打开 Q1/Q3 -> VBAT 给 VSYS/3V3 供电 -> MCU 启动
- MCU 启动后**必须尽快把 POWER_CTL(GPIO40)拉高**,才能保持这个"锁"闭合,否则松开按键后电路会自动断电
- 把 POWER_CTL 拉低,即可实现软件关机(前提是没在按着 BUTTON)

**但是** VBUS(USB供电)是通过二极管 D1 直接给 VSYS 供电的,和这个电池锁存电路是并联、互不影响的关系。
也就是说:**只要用 USB 供电测试,不用管 POWER_CTL,板子就能一直跑**,不会因为没锁存就自动断电。
以后写正式固件、要用电池供电运行时,一定记得在 `setup()` 里加上:
```cpp
pinMode(POWER_CTL_PIN, OUTPUT);
digitalWrite(POWER_CTL_PIN, HIGH);
```

## 测试顺序

1. **esp32s3_serial_test** — 确认 USB 能下载固件、主控芯片能跑起来、串口能打印
2. **esp32s3_i2c_scan_test** — 扫描 AS5600 和 DRV2605L 两条 I2C 总线,读 AS5600 角度,读 KEY 电平和电池电压
3. **esp32s3_motor_test** — 使能 DRV2605L(先拉高 M_EN),播放内置震动效果,确认马达链路
4. **esp32s3_lcd_id_test** — 不依赖显示库,原始 SPI 读屏幕 ID,快速确认 SPI 接线通不通
5. **esp32s3_lcd_fill_test** — 用 TFT_eSPI 库真正把屏幕点亮,循环填色+显示文字,肉眼确认画面正常

每个工程都是独立的 PlatformIO 项目,用 VSCode + PlatformIO 插件分别打开对应文件夹,
点 Upload 烧录、`pio device monitor` 看串口输出即可,具体步骤见各工程自己的 README.md。

## 屏幕型号提醒

数据手册(`2.8寸SPI接口模块28003数据手册`)写的是 **ST7789V 或 ILI9341V 二选一**(看实际贴片是哪颗芯片,
这两个型号常见于同一系列不同批次)。`esp32s3_lcd_fill_test` 工程建了两个 env,先试 `lcd_st7789`,
花屏/不显示的话切到 `lcd_ili9341`,不用改任何代码,重新选 env 烧录就行。
