# LCD 点亮测试(TFT_eSPI 填色 + 文字)

> ⚠️ **旧板引脚，在当前硬件上跑不通。** `platformio.ini` 里写死的是改版前的 GPIO：
> `CS=9 DC=10 SCLK=11 MOSI=12 RST=13 BLK=14`。
> 当前板已整组改为 **`CS=13 DC=12 SCLK=14 MOSI=21 RST=47 BLK=11`**。
> 注意新板的 **GPIO11 是背光**,旧配置把它当 SCLK —— 会看到背光疯闪、屏幕全黑。
> 仅作历史参考，**不要直接烧到现在的板子上**。
>
> 另:实际装的屏用 **240×240** 有效区(见仓库根 `README.md`),不是这里假设的 240×320。

引脚已根据**改版前**的原理图核实,配置在 `platformio.ini` 的 build_flags 里(TFT_eSPI 标准用法,
不需要碰库文件里的 User_Setup.h)。

数据手册显示这块屏是 **ST7789V 或 ILI9341V 二选一**,所以本工程有两个 env,
不确定具体贴的哪颗芯片时,两个都试一下就知道了。

## 使用步骤

1. VSCode + PlatformIO 打开本文件夹
2. 先烧 `lcd_st7789` 环境:
   ```bash
   pio run -e lcd_st7789 -t upload
   ```
3. 观察屏幕:如果画面正常显示(颜色循环变化+文字+一个左右移动的圆),测试通过,不用再试另一个 env
4. 如果花屏/白屏/颜色不对/完全不显示,改烧 `lcd_ili9341` 环境:
   ```bash
   pio run -e lcd_ili9341 -t upload
   ```

## 预期现象

- 屏幕每秒切换一次整屏颜色(红→绿→蓝→白→黑循环)
- 左上角显示 "ESP32-S3 LCD OK" 和当前帧号
- 屏幕下方有一个橙色圆点持续左右移动(证明画面是实时刷新的,不是卡在某一帧)

## 排查提示

| 现象 | 可能原因 |
|---|---|
| 背光亮,但完全无画面/白屏/黑屏不变 | CS/DC/SCK/MOSI/RST 接线问题,或者驱动型号选错了(换另一个 env 试试) |
| 花屏、颜色错乱、显示错位 | 驱动型号选错了(ST7789 ⇄ ILI9341 互换试);或者 SPI 频率太高(可以把 platformio.ini 里 `SPI_FREQUENCY` 先降到 `10000000` 试试) |
| 画面显示但是镜像/方向不对 | 正常现象,调整代码里 `tft.setRotation()` 的参数(0~3)即可,不影响"能不能点亮"这个结论 |
